# Gusto · Guia rápido

O Gusto reúne **receitas, pedidos de preparo, entregas, créditos e agenda** em um só lugar. Este guia mostra o essencial.

## Primeiro acesso
1. Abra o aplicativo e entre com o usuário e a senha que o administrador informou. O usuário inicial do sistema é `root`.
2. Um **guia animado** abre sozinho na primeira entrada de cada usuário. Ele verifica o ambiente, ajusta acessibilidade e apresenta a barra de ícones. Para rever, use **⋯ Mais › Guia de boas-vindas**.
3. O root é convidado a **trocar a senha inicial** logo no começo. Faça isso.

## A barra de ícones (dock)
| Ícone | Para que serve |
|---|---|
| 🏠 Início | Seus painéis. Só o assistente de receitas começa aberto |
| 🃏 Cartas | Receitas e pedidos como cartas de baralho, com filtros |
| 📦 Pedidos / Demandas | Acompanhar cada etapa, do pedido ao feedback |
| 📅 Agenda | Arrastar receitas e preparados para um horário |
| ⭐ Carteira | Créditos, saldo, mercado e links de pagamento |
| 🧭 Mapa | Mapa limpo da sua região, com a distância dos criadores; 🎲 liga as decorações |
| ⋯ Mais | Feed, grafo 3D, lista de receitas, perfil, guia |
| 🗂️ Guardados | Painéis minimizados (como a lixeira do macOS) |
| 🔔 Avisos | Notificações; o número mostra as não lidas |

A barra se ajusta ao número de ícones. Painéis **fechados** (×) viram um ícone próprio ao lado de 🗂️.

## Painéis
- **–** guarda o painel em 🗂️ Guardados.
- **×** fecha o painel; o ícone dele fica na barra para reabrir.
- **Restaurar layout padrão** (no fim de Início) volta ao estado inicial.

## Receitas: provadas e experimentos
- 🏅 **Já provada**: tem feedbacks suficientes, nota média 4 ou mais e ao menos uma evidência (vídeo ou foto).
- 🧪 **Experimento (IA)**: criada pelo assistente, ainda sem prova de conceito.
- ⏳ **Em prova** e **Sem avaliação**: receitas de usuários que ainda não atingiram a prova.

## Perguntas frequentes
**Por que não consigo aceitar um pedido?** Preparador e entregador precisam de autorização válida emitida por um fiscal.
**O que é “termos acordados”?** O preço que quem aceita definiu e o cliente cobriu em créditos. O valor fica em custódia até a entrega.
**Meus dados ficam onde?** Na versão publicada para teste, no próprio navegador. No servidor, no banco de dados instalado.

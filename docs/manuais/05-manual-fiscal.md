# Manual do Fiscal

A função de **Fiscal** é reservada: só existe para usuários criados pelo **administrador** com esse papel. Ninguém se torna fiscal por conta própria.

## Rotina
1. Em **🏠 Início**, abra o painel **Fila de supervisão**.
2. Para cada solicitação, veja os dados, o link de vídeo ou fotos e o checklist declarado.
3. Faça a inspeção virtual e **confirme cada item** do checklist.
4. **Aprovar e emitir permissão** gera um número (PRP para preparadores, ENT para entregadores) com validade de 1 ano. **Reprovar** exige um motivo, que o solicitante recebe em 🔔 Avisos.

## Boas práticas
- Só aprove com todos os itens confirmados.
- Registre o motivo da reprovação de forma objetiva.
- Você não pode aprovar o próprio registro.
